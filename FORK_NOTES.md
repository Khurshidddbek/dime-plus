# Мой форк Dime

Ветка personal. Ничего не собирал и не запускал, весь код проверен только чтением. Первая сборка в Xcode почти наверняка даст ошибки компиляции, их надо будет поправить по месту.

## Что поменял

Общее
- iOS 17.0 во всех 4 таргетах, убрал swiftlint из сборки и привязку схемы к региону SG
- свои идентификаторы в одном файле app/dime/Utilities/AppIdentifiers.swift, схема ссылок dimefork, чтобы не пересекаться с Dime из App Store
- русский язык подключен для приложения и виджетов, все новые строки есть на en и ru
- убрал tip jar, ссылки на отзывы и соцсети

Суммы
- один форматтер на все приложение: разряды через узкий пробел, у UZS и других валют без копеек дробной части нет никогда, длинный символ после числа (35 880 000 so'm)
- короткая запись (35,9 млн) только там, где мало места: оси графиков, мелкие виджеты. Полная сумма по тапу
- максимум 12 цифр

Сохранность данных
- сохранения больше не глотают ошибки: если не сохранилось, экран не закрывается и видно "Не удалось сохранить"
- удаление с настоящей отменой, Недавно удаленные хранят записи 30 дней
- автобэкап раз в день в Documents/Backups (последние 14), видно в Файлах. В Настройках: сделать бэкап, поделиться, восстановить
- журнал диагностики в Настройках
- если база не открылась, показывается экран восстановления вместо падения
- виджеты и расширения открывают базу без CloudKit, валюта не затирается из iCloud при запуске, повторяющиеся записи создаются независимо от iCloud

Журнал
- один запрос на весь список, строки как значения, свайп не мешает скроллу
- поиск по заметке, категории и сумме
- меню строки: дублировать, записать еще раз сегодня, скопировать сумму
- блокировка приложения закрывает и открытые экраны поверх журнала

Добавление записи
- заметка без старого лимита в 50 символов: до 4 видимых строк, предел 300 символов, счетчик появляется с 240
- сумма с разрядами, для UZS режим целых чисел с кнопкой 000
- подсказки заметок из истории сразу ставят категорию, частые категории чипами
- подтверждение при закрытии с несохраненным вводом
- долгое нажатие на галочку сохраняет и оставляет экран для следующей записи

Аналитика
- переделал целиком: список категорий, где каждая строка нажимается, полоса долей с группой Другое, экран категории с ее записями и трендом, честное сравнение с прошлым периодом, среднее за день

Бюджеты, категории, импорт, настройки
- починил кнопку следующего периода у годового бюджета, "месяцев назад" для годового, маркер цели, падения при нулевом бюджете
- удаление категории показывает, сколько в ней записей, и дает перенести их в другую
- импорт CSV: читает экспорт из App Store Dime, кавычки по RFC 4180, разные кодировки, показывает что будет импортировано до записи, пишет одним куском
- экспорт в CSV и JSON
- новые экраны: Резервные копии, Недавно удаленные, Диагностика, статус iCloud

Виджеты и команды
- суммы в том же стиле, период бюджета считается правильно после смены месяца, убрал force unwrap

SMS банка
- парсер Humo и Uzcard, входящие с проверкой, правила по продавцу (можно включить автодобавление), свои карты
- переводы между своими картами и снятие в банкомате по умолчанию предлагается пропустить
- три входа: автоматизация в Командах, вставка одного или нескольких SMS, чип "вставить из буфера" в журнале
- данные лежат в JSON в app group, модель Core Data не трогал

## Как запустить на своем iPhone

1. Открыть app/dime.xcodeproj в Xcode 15 или новее. Если Xcode предложит Update to recommended settings, отказаться
2. Для каждого из 4 таргетов (dime, ExpenditureWidgetExtension, BudgetIntent, BudgetIntentUI) в Signing & Capabilities выбрать свою команду. Automatically manage signing включен
3. Bundle id уже стоят: uz.khurshidbek.dime, uz.khurshidbek.dime.ExpenditureWidget, uz.khurshidbek.dime.BudgetIntent, uz.khurshidbek.dime.BudgetIntentUI
4. App group: group.uz.khurshidbek.dime. iCloud контейнер: iCloud.uz.khurshidbek.dime. С платным аккаунтом Xcode создаст их сам при первой сборке. Если в контейнере нажать красную ошибку, помогает кнопка обновления в списке контейнеров
5. Если хочется другие идентификаторы, менять в трех местах сразу: AppIdentifiers.swift, 4 файла entitlements, bundle id в таргетах (и URL scheme в app/dime/Info.plist)
6. Выбрать схему dime, свой iPhone, Run. На телефоне включить Developer Mode и доверить сертификат в Настройки - Основные - VPN и управление устройством

С бесплатным Apple ID
- iCloud и push на бесплатной команде недоступны. В Signing & Capabilities у всех 4 таргетов удалить iCloud и Push Notifications (или убрать из entitlements ключи aps-environment и все com.apple.developer.icloud-*, com.apple.developer.ubiquity-kvstore-identifier). App Groups оставить
- в AppIdentifiers.swift поставить cloudSyncEnabled = false, иначе CloudKit упадет при запуске без entitlement
- приложение живет 7 дней, потом пересобрать. Данные при пересборке остаются, если не удалять приложение. На всякий случай перед этим сделать бэкап в Настройках
- синхронизации между устройствами не будет, бэкапы в Файлах работают

## Как перенести данные из App Store Dime

1. В старом Dime: Settings - Export Data, сохранить CSV в Файлы
2. В форке сначала создать те же категории (названия один в один, тогда они привяжутся сами)
3. Настройки - Импорт Данных, выбрать файл. Формат старого экспорта определяется сам, колонки и формат даты подставляются
4. На шаге привязки категорий проверить пары, на экране проверки посмотреть сколько строк импортируется и сколько пропущено
5. Перед записью делается бэкап pre-import, откатиться можно в Настройки - Резервные копии

Что теряется: повторы (повторяющиеся записи придут как обычные), бюджеты, цвета и эмодзи категорий, валюта. Строки с суммой 0 и с непривязанной категорией пропускаются. Повторный импорт того же файла дубли не создает.

Первый импорт лучше проверить на паре месяцев: сверить сумму за месяц со старым приложением.

## Автоматизация SMS в Командах

То же самое по шагам есть в приложении: Настройки - SMS банка - Настроить автоматизацию.

1. Открыть Команды, вкладка Автоматизация, нажать +
2. Выбрать Сообщение
3. Сообщение содержит: ввести HUMOCARD (для Humo). Для Uzcard сделать вторую такую же автоматизацию со словом karta или Miqdor. Отправителя не заполнять
4. Выбрать Немедленный запуск, выключить Уведомлять о запуске, Далее
5. Новая пустая автоматизация, Добавить действие, найти Dime, выбрать Add Bank SMS (Добавить SMS банка)
6. В поле текста сообщения выбрать Ввод быстрой команды (Shortcut Input), Готово
7. Проверить: в приложении на экране настройки есть кнопка с тестовым сообщением, а после первого настоящего SMS там же появится время последнего сообщения

Как работает дальше: SMS приходит, команда молча передает текст в приложение, запись попадает во входящие. В журнале сверху появляется карточка Сообщения банка. Там можно добавить свайпом вправо, пропустить свайпом влево, открыть полный экран записи. Для продавца можно включить "всегда добавлять", тогда такие SMS будут записываться сами.

Названия пунктов в русских Командах писал по памяти, на телефоне могут чуть отличаться.
